# UAI utilities

Install with `npm install github:rodkisten/uai#main` after merge. Import `@rodkisten/uai/logger`, `@rodkisten/uai/summary`, or `@rodkisten/uai/ci`. Native Node ESM; no compilation required. The shadcn registry remains separate.

Migrated from userscripts-cf scripts/utils; CI re-exports summary helpers for compatibility.
